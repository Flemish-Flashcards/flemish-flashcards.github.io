# Flemish Flashcards

Learn Flemish (Dutch as spoken in Belgium) with flashcards: picture cards for beginners,
A2 and B1 vocabulary, real everyday Flemish ("Echt Vlaams"), a guide to the tricky Dutch
sounds, and quizzes.

**Website:** https://flemish-flashcards.github.io/

(Until November 2026 the site lived at digstraightthrough.github.io/flemish-flashcards/; that address now
forwards visitors here together with their saved progress.)

Sister site: [Greek Flashcards](https://greek-flashcards.github.io/).

Plain HTML and JavaScript, no build step: open `index.html` in a browser.
Visits are counted with GoatCounter (no cookies, no personal data).
